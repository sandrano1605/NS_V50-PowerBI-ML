# Ventana mensual V39

- Universo fuente: tres meses calendario incluyendo el mes actual al momento de la actualización.
- Ejemplo al 23-07-2026: mayo, junio y julio 2026.
- Selector: Mes de creación, con mes actual seleccionado mediante PeriodoKey = 0.
- El gráfico comparativo ignora la selección mensual y siempre muestra los tres meses para facilitar la tendencia.
- La fecha de actualización visible corresponde al máximo PED_FECHA_HORA del set completo, incluyendo pedidos no facturados.
- Barras apiladas: promedio macro Administrativo y macro Operaciones.
- Línea: promedio interno total de pedidos cerrados y evaluables.
