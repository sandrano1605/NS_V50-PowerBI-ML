# REQ-007 · Reparación estructural automática

Este archivo activa el workflow de reparación y validación después de que el workflow ya existe en la rama.

Criterio de salida:

- todos los JSON parsean;
- todos los visuales tienen estructura mínima válida;
- referencias de tablas, columnas y medidas existen;
- no quedan medidas SVG dinámicas proyectadas;
- posiciones y dimensiones son válidas;
- nombres de visual no están duplicados dentro de una página.
