# Paleta semántica del reporte

La misma categoría debe conservar el mismo color en todo el proyecto.

| Concepto | Color |
|---|---|
| Normal | `#1976D2` |
| FES total | `#F0A500` |
| FES puro | `#F6C453` |
| FES + Saldo | `#D97706` |
| Saldo puro | `#7B1FA2` |
| En SLA | `#2E8B57` |
| Fuera de SLA | `#D3392C` |
| Administrativo | `#1976D2` |
| Operaciones | `#F0A500` |
| Promedio total | `#1B365D` |

El Resumen Ejecutivo utiliza esta paleta de forma explícita en los SVG para evitar que Power BI reasigne colores por orden de serie.
